# QuickBite MySQL Company-Level Challenge — Task 5

Welcome to the **Task 5** directory of the QuickBite challenge from Kiran Academy[cite: 2]. This document serves as the project README, detailing the database architecture, challenge tiers, and learning objectives for this practical MySQL project[cite: 2].

---

## 📋 Project Overview

As a Junior Database Developer at **QuickBite Technologies Pvt. Ltd.**, the objective is to analyze restaurant data, cuisines, cities, ratings, pricing, order counts, and delivery performance using MySQL[cite: 2]. The challenge simulates real-world business scenarios where SQL developers translate company requirements into structured database queries[cite: 2].

---

## 🏢 Database Architecture (`quickbite`)

The database is built using a single primary table named `restaurants` containing 30 demo records[cite: 2]:

* **Table Name:** `restaurants`[cite: 2]
* **Primary Key:** `restaurant_id`[cite: 2]
* **Key Attributes:** `restaurant_name`, `cuisine`, `city`, `rating`, `avg_order_value`, `orders_count`, `delivery_fee`, `est_delivery_time`, `owner_name`, and `brand`[cite: 2].

---

## 🏆 Challenge Levels & Structure

The challenge is divided into progressive technical levels and classroom competition points[cite: 2]:

| Stage / Level | Focus Area | Tasks Covered |
| :--- | :--- | :--- |
| **Level 1 — Food Detective** | Basic filtering, comparison, ranges, and lists (`WHERE`, `BETWEEN`, `IN`, `LIKE`)[cite: 2] | Tasks 1–10[cite: 2] |
| **Level 2 — Recommendation Team** | Sorting, uniqueness, aliasing, and limiting (`ORDER BY`, `DISTINCT`, `LIMIT`)[cite: 2] | Tasks 11–20[cite: 2] |
| **Level 3 — Find the Hidden Restaurants** | Advanced pattern matching and wildcards (`LIKE`)[cite: 2] | Tasks 21–28[cite: 2] |
| **Level 4 — Business Team** | Multi-condition filtering (`AND`, `OR`, `!=`)[cite: 2] | Tasks 29–38[cite: 2] |
| **Level 5 — Boss Challenges** | Analytical queries, aggregates (`AVG()`), and multi-factor filtering[cite: 2] | 8 Challenges[cite: 2] |
| **FINAL BOSS — CEO Challenge** | Comprehensive enterprise reporting (combining multi-level filters, sorting, and limits)[cite: 2] | 1 Challenge[cite: 2] |

## 💡 Key SQL Concepts Practiced

* Database and table creation (`CREATE DATABASE`, `CREATE TABLE`)[cite: 2]
* Data manipulation and data query language (`INSERT`, `SELECT`)[cite: 2]
* Conditional operators and pattern matching (`WHERE`, `AND`, `OR`, `NOT`, `BETWEEN`, `IN`, `LIKE`)[cite: 2]
* Result organization (`DISTINCT`, column aliases, `ORDER BY ASC/DESC`, `LIMIT`)[cite: 2]
* Aggregate functions (`AVG()`)[cite: 2]
