# 📘 Kiran Academy Java Full-Stack Internship Program

## 📌 Program Overview

The **Kiran Academy Java Full-Stack Internship Program** includes a rigorous database module designed for backend mastery. Scheduled as a dedicated part of the weekly curriculum (specifically assigned for 3 days a week), this training bridges the gap between core Java/Spring Boot development and robust database management by taking interns from foundational SQL scripts up to advanced enterprise-level analytics.
