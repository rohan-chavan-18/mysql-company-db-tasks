# ecommerce product inventory management - sql practical

## project description
this project is a simple sql practice assignment based on e-commerce product inventory management using ddl, dml, select, update and delete operations.

## database name
ecommerce_db

## table name
products

## table structure
- product_id (int, primary key)
- product_name (varchar)
- category (varchar)
- brand (varchar)
- price (decimal)
- quantity (int)
- city (varchar)
- status (varchar)

- create database
- create table
- insert records
- select queries
- where clause
- logical operators (and, or, not)
- between operator
- in operator
- like operator
- update queries
- delete queries
